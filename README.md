ChinaCalcProject

Веб-приложение на Django для расчёта стоимости доставки товаров из Китая в Россию и Беларусь.
Система учитывает стоимость закупки, ручные курсы валют, логистику по весу или объёму, комиссию байера, 
дополнительные услуги и итоговую прибыль.
Для каждой поставки можно сформировать Excel-отчёт.

Возможности:
>создание и редактирование поставок;
>добавление товаров, привязка их к клиентам и поставкам;
>маршруты доставки и разные виды транспорта;
>расчёт логистики по весу или объёму;
>ручной ввод курсов валют;
>отдельные курсы для клиента и для расчета себестоимости;
>индивидуальная комиссия байера для каждого клиента;
>учёт проверки товара, фотоотчёта и упаковки;
>расчет стоимости товара для клиента и для себя;
>расчёт себестоимости, итоговой цены для клиента и прибыли;
>экспорт отчёта по поставке в Excel;
>сервис доступен только авторизированным пользователям.

Поддерживаемые валютные направления
CNY → BYN;
CNY → RUB;
USD → BYN;
USD → RUB;
RUB → BYN.

Курсы вводятся вручную. Для расчёта себестоимости используются внутренние курсы, а для цены клиента — клиентские.
Основные расчёты для каждой товарной позиции:
>стоимость закупки = цена × количество × внутренний курс
>стоимость закупки для клиента = цена × количество × клиентский курс
>комиссия байера = стоимость для клиента × процент комиссии / 100

Логистика рассчитывается выбранным для поставки способом:
>по весу = вес × тариф за 1 кг
>по объёму = объём × тариф за 1 м³
прим.: тарифы вводятся вручную 

Итоговые показатели поставки включают:
>стоимость товара;
>стоимость товара для клиента;
>логистические расходы;
>дополнительные услуги;
>комиссию байера;
>себестоимость;
>итоговую стоимость для клиента;
>прибыль.

Установка

1. Клонирование проекта
git clone <https://github.com/Dimaarti/Project_TMS>
cd ChinaCalcProject

2. Установка зависимостей
poetry install

3. Настройка окружения
Создайте файл .env и укажите секретный ключ, режим отладки и подключение к PostgreSQL.

Пример:
SECRET_KEY=key
DEBUG=True

DB_NAME=name
DB_USER=user
DB_PASSWORD=password
DB_HOST=localhost
DB_PORT=5432

Прим.: Названия переменных должны совпадать с теми, которые читаются в настройках проекта.

4. Применение миграций
python src/manage.py migrate

5. Создание администратора
python src/manage.py createsuperuser

6. Запуск сервера

python src/manage.py runserver

После запуска приложение будет доступно по адресу:
http://127.0.0.1:8000/

Работа с приложением:
Создайте учётную запись и войдите в систему.
Зайдите в панель администратора и создайте маршрут, а также добавьте продукт (LOGISTICS: маршруты доставки и SHIPMENT: продукты).
Дальше переходим по адресу http://127.0.0.1:8000/client/ и нажимаем добавить клиента в правом верхнем углу.
Добавьте клиентов (обязательные поля: пользователь, чей клиент; полное имя клиента; номер телефона и процент комиссии байера).
Далее переходим http://127.0.0.1:8000/finance/ - 
в правом верхнем углу нажимаем кнопку добавить курсы. 
Добавляем внутренние и клиентские курсы.
Далее переходим http://127.0.0.1:8000/shipment/ -
в правом верхнем углу кнопка Создать поставку.
Создаем поставку и задаем вручную номер поставки, тариф за 1 кг или тариф за 1 м3 (оба по дефолту = 0),
статус поставки (по дефолту = Создана), способ расчета логистики (по весу или по объему), вес или объем (в зависимости от способа расчета логистики),
а также выбираем маршрут поставки, обменные курсы валют, валюту тарифа, валюту итогового расчета, также есть поле примечание.
Нажимаем создать 
Переходим в подробнее созданной поставки (там ее можно редактировать, удалить или вернуться ко всем поставкам).
Далее нажимаем кнопку Добавить товар и выбираем клиента, товар, а также задаем вручную ссылку на товар, трек-номер,
количество штук, цена за единицу товара, валюта цены (по дефолту = CNY), 
проверка товара - фотоотчет - упаковка (по дефолту = USD).
Добавляем товары в поставку.
Нажмите «Рассчитать».
При необходимости скачайте Excel-отчёт.
Отчёт не формируется, если в поставке нет товаров.
Также при нажатии открыть товар, переход по ссылке на товар.
